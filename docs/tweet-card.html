The hidden culprit:
your monitor's FreeSync setting

ROOT CAUSE — confirmed by A/B experiment on Mac mini M4
Why it breaks
FreeSync adds handshake overhead your Mac never uses
macOS outputs no VRR at 60Hz desktop work — but the monitor still negotiates Adaptive-Sync every wake, and deadlocks into a half-locked state.
How we proved it
3 controlled experiments, kernel-level evidence
Bandwidth math excluded the cable; physical hotplug monitoring; then a clean A/B test with FreeSync off.
✓ 4/4 hotplugs rebuilt in 0.3s ✓ EDID intact, 0 errors ✓ Wake test clean after fix
The fix — free, 30 seconds
1. Turn OFF FreeSync in monitor OSD
2. Or run our wake-resync daemon
display-resync = a software cable replug: one-shot fix, or auto-resync 2.5s after every system wake. No more pulling cables.
